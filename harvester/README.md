# جمع‌آوری کامل محتوای آماری (Harvester)

خزنده‌ای که **کل** محتوای قابل‌استخراج سایت‌های هدف را کشف، دانلود و ساماندهی می‌کند.
لینک‌های نمونه فقط نقطه شروع هستند؛ بقیه صفحات به‌صورت خودکار از لینک‌های داخلی،
`sitemap.xml` و `robots.txt` کشف می‌شوند.

## سایت‌های پیکربندی‌شده

| سایت | پوشه خروجی |
|---|---|
| amar.org.ir | مرکز آمار ایران |
| iranstatis.com | ایران استاتیس |
| imidro.gov.ir | ایمیدرو |
| mimt.gov.ir | وزارت صمت |
| behinyab.ir | بهین یاب |
| maj.ir | وزارت جهاد کشاورزی |

## اجرا

```bat
cd /d "D:\استخراج امار\harvester"
python harvester.py                      :: همه سایت‌ها
python harvester.py --site ایمیدرو        :: یک سایت
python harvester.py --parallel 2         :: دو سایت هم‌زمان
python harvester.py --limit 50           :: تست با سقف ۵۰ صفحه
python harvester.py --delay 0.2          :: درخواست سریع‌تر
```

یا دوبار کلیک روی `run.bat`.

## خروجی

ریشه خروجی **همان پوشه‌ای است که اسکریپت در آن اجرا می‌شود** (`output_root: "."`
در `config.json`). اگر `run.bat` را اجرا کنید، همه‌چیز کنار خود اسکریپت ساخته می‌شود.

برای هر سایت:
- `صفحات/` — HTML و متن خالص هر صفحه
- `فایل‌ها/` — PDF، Excel، Word، ZIP و… (نام اصلی فارسی + هش یکتا)
- `جدول‌ها/` — جدول‌های هر صفحه به CSV
- `داده-جاسازی‌شده/` — JSONهای درون‌صفحه (داده‌های نمودار/درخت)
- `_manifest.json` — وضعیت دانلود (برای ادامه از نقطه قطع)
- `_discovered.json` — همه آدرس‌های کشف‌شده

در ریشه:
- `فهرست-دانلودها.csv` — فهرست کامل
- `metadata.jsonl` — متادیتای کامل هر آیتم (یک JSON در هر خط)
- `metadata.csv` — همان متادیتا برای استفاده در اکسل/نرم‌افزار دیگر
- `config.discovered.json` — کانفیگ کامل ساخته‌شده از نتایج خزش

## متادیتا

برای هر فایل/صفحه/جدول یک رکورد ثبت می‌شود:

| فیلد | توضیح |
|---|---|
| `id` | شناسه یکتا (هش آدرس) |
| `type` | `file` / `page` / `table` / `embedded_json` |
| `source_site` | نام منبع (مثلاً ایمیدرو) |
| `source_site_url` | آدرس اصلی سایت |
| `source_domain` | دامنه منبع |
| `source_page` | صفحه‌ای که لینک فایل در آن بود |
| `source_url` | **لینک دقیق فایل/صفحه** |
| `final_url` | آدرس نهایی پس از ریدایرکت |
| `title` | عنوان صفحه یا نام فایل |
| `file_name` / `local_path` | نام و مسیر نسبی فایل ذخیره‌شده |
| `text_path` | مسیر متن خالص (برای صفحات) |
| `content_type` | نوع MIME |
| `size_bytes` / `sha1` | حجم و هش محتوا |
| `downloaded_at` | زمان دانلود |
| `depth` / `fragment` | عمق خزش و شماره جدول/JSON |

## کانفیگ

`config.json` تنظیمات هر سایت را دارد:

| کلید | معنا |
|---|---|
| `start_urls` | نقطه‌های شروع (فقط شروع، نه فهرست کامل) |
| `allowed_hosts` | دامنه‌های مجاز |
| `max_depth` | عمق خزش |
| `max_pages` | سقف صفحات |
| `delay` | فاصله بین درخواست‌ها |
| `exclude_patterns` | الگوهای حذف (regex) |
| `extract_tables` | استخراج جدول‌ها به CSV |
| `sitemap` | خواندن sitemap |

پس از هر خزش، `config.discovered.json` با بخش‌های کشف‌شده بازنویسی می‌شود و
می‌توانید آن را به‌عنوان کانفیگ اجرا کنید:

```bat
python harvester.py --config config.discovered.json
```

## نگهداری

```bat
python cleanup.py           :: پیش‌نمایش فایل‌های تکراری
python cleanup.py --apply   :: حذف تکراری‌ها
```

## نکته‌ها

- اجرای مجدد فقط موارد جدید را می‌گیرد (resume).
- اگر سایتی از شبکه فعلی مسدود باشد، پس از ۸ خطای پیاپی خودکار رها می‌شود.
- فایل‌های تکراری بر اساس هش محتوا ذخیره نمی‌شوند.
- برای دسته‌بندی هوشمند: `--ai` (مدل روی `ai.ismc.ir`).
